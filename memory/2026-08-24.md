# LimboTranslate — состояние на 2026-08-24

## Что делаем
Полный аналог **QTranslate** (QuestSoft) **для Windows** (не macOS!). Требование пользователя: та же архитектура и функционал, **без единой платной подписки/ключа**.

## Ключевые решения
- Стек: **C# .NET 8 + WPF**, net8.0-windows10.0.19041.0, win-x64, PublishSingleFile, self-contained.
- Установщик: **Inno Setup** (free). Подпись кода не берём.
- Сборка: **GitHub Actions windows-latest** (dotnet локально НЕТ, разработка на macOS — компилировать локально нельзя, только писать код).
- Движки: **Google** (translate.googleapis.com/translate_a/single, без ключа) + **DeepL** (неофициальный www2.deepl.com/jsonrpc, без ключа). Провайдеры — плагины через ITranslationProvider.
- Фичи v1: глобальные хоткеи + popup у курсора, вкладки сравнения сервисов, история переводов (SQLite).
- Хоткеи: Ctrl+Q (перевод), двойной Ctrl (popup), Ctrl+E (озвучка), Ctrl+Shift+Q (главное окно).
- Тёмная тема: Bg #1E1E1E, Panel #252526, Text #E0E0E0, Accent #0E7AC4, Border #3F3F46, Segoe UI 13.
- Настройки/БД: %APPDATA%/LimboTranslate/settings.json и history.db.
- Комментарии в коде не писать. KISS.
