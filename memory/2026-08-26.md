## Публикация
- Локально собрать нельзя (macOS, нет dotnet). Сборка только через GitHub Actions.
- Пуш: `git push https://88g7rg9nyp-dot:<TOKEN>@github.com/88g7rg9nyp-dot/LimboTranslate.git main:main`
- Релиз создаётся ТЕГОМ: `git tag vX.Y.Z && git push <url> vX.Y.Z` → Actions собирает exe + Inno Setup installer.
- Проверка: `curl -s -H "Authorization: token <TOKEN>" "https://api.github.com/repos/88g7rg9nyp-dot/LimboTranslate/actions/runs?per_page=1"`
- Сборка идёт ~3 минуты. Токен пользователя засветился в чате (ghp_TS4IWO7...), рекомендован отзыв.

## Открытые вопросы
1. ВЫЛЕТЫ приложения — причина неизвестна, ждём crash.log от пользователя.
2. DeepL по-прежнему может отдавать 429 (неофициальный эндпоинт).
3. Локальный офлайн-переводчик (Argos/CTranslate2) обсуждался — отложено, дорого (~150 МБ моделей).

## ТЕКУЩАЯ ЗАДАЧА (в работе)
Замена текста прямо в поле ввода: выделил "ПРИВЕТ" в редактируемом поле → значок → клик → текст в поле заменяется переводом.
План:
- SelectionCapture: IsEditableFocused() (ValuePattern не readonly / ControlType Edit|Document), ReplaceSelectionAsync(text) через буфер + Ctrl+V с восстановлением буфера.
- SelectionIconWindow: запомнить GetForegroundWindow() при показе, при клике SetForegroundWindow, если поле редактируемое → перевести и вставить, иначе обычный попап.
